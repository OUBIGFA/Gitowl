# Go 后台与直接调用 Git

生产路径为 `MyGo → 同进程 Go 状态层 → 随包的官方 Git`。基础安装不包含 Node、Electron、JavaScript 业务 bundle、Keytar 或 Koffi。Node 仍是源码构建和旧格式兼容测试的开发工具。

## 复用依据

对照 [51code 的固定修订](https://github.com/ysicing/51code/tree/128dbe5850f5387dece67e616c1b1116b411927d)：它使用 Go/MyGo、外部 Git、后台检查和局部更新，Windows 版也携带 Git/SSH/LFS。其 README 同时说明克隆、交互式 rebase、认证设置等功能边界。轻量来自进程结构、按需工作和功能范围，不能用不同平台的安装包直接比较。

Gitowl 参考这些行为，不复制其 AGPL 源码。Git 参数与机器输出使用 [Git 官方文档](https://git-scm.com/docs)。部分行 patch 格式沿用本项目 MIT 上游 `app/src/lib/patch-formatter.ts` 的规则。原生界面、系统服务和 SQLite 复用锁定的 MyGo；账户使用 MyGo Secrets 的旧 Keytar 服务名兼容接口。

## 读取与刷新边界

- 所有仓库共用一个 32 MiB LRU。预算包括内容、键和每条记录 128 字节开销；单个缓存对象不超过 8 MiB。仓库切换不创建新的独立预算。
- 不可变内容按 common Git directory 与对象 ID 保存。完整提交 ID 下的路径解析、历史页、差异、改动列表和统计也共用这一预算。可变引用重新解析。同键并发读取共用一次任务。
- `cat-file --batch-check -Z` 先读取对象大小。超限明确报错，不把截断内容当成完整文件。缺失对象与 Git 执行失败分别处理。
- 只监听当前仓库的工作目录和 Git 目录。通知合并为 200 ms；无变化通知逐步退避到 8 秒。每分钟校准状态，每五分钟校准元数据；回到窗口时检查状态。
- 元数据按真实 refs/config/worktree 内容判断变化，临时锁和恢复记录不会反复加载历史。状态指纹包含已修改文件的内容，能检测同大小继续编辑。状态未变不发布新快照。
- 图片是当前预览的独立预算：两侧压缩内容合计不超过 64 MiB。只保留当前预览，切换仓库或文本文件时释放。解码进程按需启动，有时间、内存和输出上限。

缓存预算不代表应用总内存上限；MyGo 控件、当前历史列表、Git 子进程和解码结果另有内存开销。

## Git 写入与恢复

普通提交使用独立 index，运行真正的 Git hook、签名与 LFS filter。未选中的真实暂存和工作目录不参与提交。部分行的原差异身份过期时拒绝提交。merge、rebase、cherry-pick 或 revert 进行中使用原生继续/中止流程。

提交前在实际 Git 目录内保留原 index 和恢复记录。开始写入后不因界面取消强杀提交；提交成功返回明确 SHA，再整理被选路径的暂存。外部程序改变暂存时保留双方数据，显示恢复入口并阻止重复提交。恢复只有在 HEAD、候选树及原暂存仍匹配时才执行；无法确定时要求查看保留文件。成功记录及丢弃前的文件副本进入回收站，回收失败保留文件并显示提示。

远程操作、克隆和可能触发 LFS 下载的切换使用原生凭据助手与 askpass。提示回复不等待业务锁。账号以 endpoint/login 绑定；其他主机继续使用用户已有 Git helper。令牌不进入命令行或仓库配置。

## 数据与模型

新状态保存在原用户资料目录的 `gitowl-native.sqlite`。首次启动只读旧 `backend-data/settings.sqlite` 和 IndexedDBShim SQLite，事务导入设置、仓库及账号关联；全部旧记录原文保存在 `legacy_records`。只有事务完成标记允许跳过迁移，失败可重试。

更早的 Chromium 资料使用旧安装内已有的引擎一次性导出。新安装器不携带旧引擎。Typeson 导出的完整原文保留，不能读取时拒绝激活空资料。原数据不删除。来源、版本及许可证见 `third_party/native-runtimes.json`。

Copilot 使用官方 Go SDK，与平台组件锁定为 `1.0.27-preview.1`。首次主动刷新模型或生成时准备组件；普通启动、Git 操作和打开普通设置不下载。下载检查归档 SHA-512 和逐文件 SHA-256，失败、取消后可重试，同版本缓存可离线复用。此版本锁定是兼容现有组件的选择，不表示 SDK 的最新版本。

自定义供应商保留六种协议，按项目锁定的官方 SDK 请求契约适配 Go HTTP。稳定 ID、凭据绑定、模型逐项启用和失效选择清空保持不变。凭据更新失败时不发布新设置。生成需确认发送范围，仅写入可审阅草稿；文件在生成期间变化则保留原草稿。模型没有 Git 工具或自动提交权限。

## 本轮功能边界

保留日常提交、部分行、amend、coauthor、分支、标签、worktree、stash、合并/rebase、冲突继续与中止、Git/LFS/hooks、克隆、账户、远程同步、图片与本地编辑。远端为空时先配置远端地址，再由用户推送。深链复用 `openRepo`、分支和已注册仓库的 PR ref 形式。

原 Node 的自动拆分多提交、历史拖动重排、后台 PR/规则/配额轮询以及 Copilot 自动冲突处理不在当前原生流程中；对应入口不展示。生成说明、普通手工提交和冲突文件编辑继续可用。这些重型调度的移除避免恢复多个常驻业务所有者，不声明上游全功能等价。自定义 shell/editor 高级配置保留原记录，文件打开使用系统关联程序。

## 验证

`npm run test:kernel` 组装真实运行资源，用锁定旧依赖生成兼容夹具，运行 Go、真实 Git、LFS、凭据子进程、图片像素、Copilot SDK 握手和生产 MyGo 控件测试。验证记录分别绑定源码/测试摘要和运行资源摘要。界面截图、性能测量与安装器核验另外记录在本地 `output/reports/`，不以编译代替实际验收。
