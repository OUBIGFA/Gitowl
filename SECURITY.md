# Security policy

Gitowl is a public derivative of GitHub Desktop. Do not report security vulnerabilities through public issues, discussions, or pull requests.

Use GitHub's private security advisory flow for [OUBIGFA/Gitowl](https://github.com/OUBIGFA/Gitowl/security/advisories/new). Include the affected revision, operating system, reproduction steps, and any relevant logs after removing credentials and private data.

The upstream application and third-party dependencies may have separate reporting policies. Follow the policy of the affected component when the issue is outside Gitowl's changes.
